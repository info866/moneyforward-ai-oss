# Maintainer contact and contributor boundaries

This is an **unofficial community-led project**. Public interaction is through the repository's Issues and Pull Requests, represented by the project maintainer GitHub account. The maintainer does not provide personal biography, home address, phone number, private employer/client details or a direct personal email here.

For a reproducible technical defect, use the [Issue templates](.github/ISSUE_TEMPLATE) and synthetic fixtures. For security disclosures, use GitHub's private vulnerability-reporting mechanism when enabled; do not publicly disclose secrets or customer financial data.

Only the project's maintained source is shareable. Contributors never gain access to the private production Money Forward deployment, financial records, authentication tokens, or company-only policies. Project ownership does not imply employment by, affiliation with, or endorsement from Money Forward, Inc.

We cannot promise response times or automatic code acceptance. Each proposed improvement is evaluated against accounting integrity, original source evidence, authorized scope, official provider read-back, replay safety, privacy and reproducible tests. Merged code is not automatically deployed to any production account.

For release status consult [docs/PUBLIC_RELEASE_SCOPE.md](docs/PUBLIC_RELEASE_SCOPE.md) and [docs/PRODUCTION_GATES.md](docs/PRODUCTION_GATES.md).
