# Provider and source-rights boundary

Checked against the Money Forward official API terms on 2026-11-11:
https://biz.moneyforward.com/agreement/api/

This release distributes owner-controlled automation source under MIT; it does
not redistribute Money Forward's service/API, credentials, SDK source, internal
documentation, customer data or logo assets. Each adopter registers/authorizes
its own permitted application and products, manages its own credentials, obtains
required user consent, and respects current scopes, API limits and data handling.
No shared maintainer API key or hosted proxy is included. Compatibility names
must not imply endorsement. The terms include restrictions on key sharing,
API-only re-provision, unauthorized access and misuse of member information.

Source publication is not a provider partnership, permission grant, or legal
opinion that every future use is compliant. A hosted/multi-customer product or
new integration needs its own contract and authorization assessment.

First-party source is published on the owner's instruction to open-source their
own system. Preserve MIT and all dependency notices. No code from the previously
compared third-party connector was imported. Future PR authors must confirm
that they may submit the patch under the repository license. An unresolved
third-party ownership or confidentiality claim blocks the affected material.
